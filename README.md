# ATP 2023 Tennis Match Dashboard

## Project Overview
An interactive data visualization dashboard analyzing 2023 ATP tennis match data.
Built for the Exploratory Data Analysis course.

## Installation
pip install -r requirements.txt

## How to Run
cd C:/Users/suhai/dashboard_project
streamlit run app.py

## Dataset
- File: apt_matches_2023.cvs.docx
- Records: 2933 matches
- Features: 49 columns

## Charts Included
1. Pie Chart - Matches by Surface
2. Histogram - Match Duration Distribution
3. Line Chart - Matches Per Month
4. Bar Chart - Top 10 Winners
5. Scatter Plot - Rank vs Aces
6. Box Plot - Winner Age by Surface
7. Heatmap - Feature Correlations
8. Area Chart - Cumulative Matches
9. Count Plot - Matches by Round
10. Violin Plot - Duration by Surface

## Insights
- Hard court matches are the most common surface type
- Match duration averages around 90 minutes
- Top ranked players tend to serve more aces
